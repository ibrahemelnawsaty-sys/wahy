# أدلّة الأدوار (طالب / معلّم / وليّ / مدير مدرسة / دعم)

هذا الدليل يشرح — بلغة عمليّة موجزة — ما يفعله كلّ دور من أدوار منصّة **أثيل مكة** (`atheel-makkah.com`) عدا السوبر أدمن. لكلّ دور لوحة تحكّم مستقلّة تُفتح بعد تسجيل الدخول، ومسارات محروسة بصلاحيّة الدور. الأدوار المشمولة: **الطالب، المعلّم، وليّ الأمر، مدير المدرسة، الدعم الفنّيّ**.

> ملاحظات عامّة:
> - كلّ الأدوار التربويّة (طالب/معلّم/وليّ/مدير مدرسة) مقيّدة بـ«المدرسة النشطة» — لا يرى المستخدم إلّا بيانات مدرسته.
> - **الرسائل** و**التذاكر** و**الإشعارات** متاحة لكلّ الأدوار.
> - جميع الأدوار — أيّاً كان دورها — تفتح تذكرة دعم فنّيّ من مسار `‏/tickets`.

---

## 1. الطالب

قلب تجربة المتعلّم: مسار تعلّم مُلعَّب (Gamified) يجمع بين الأنشطة والتمارين والنقاط والمستويات والشارات والتحدّيات والمتجر.

### التعلّم والأنشطة

| العنصر | الوصف | المسار |
|---|---|---|
| لوحة التحكّم | نظرة عامّة على التقدّم والمهامّ | `‏/student/dashboard` |
| مسار التعلّم | خريطة الدروس المتسلسلة | `‏/student/path` |
| الدرس | محتوى الدرس التعليميّ | `‏/student/lesson/{id}` |
| النشاط | حلّ النشاط وتسليمه | `‏/student/activity/{id}` → إرسال عبر `activity.submit` |
| التمارين | قائمة التمارين المتاحة | `‏/student/practice` |
| القيم | شجرة القيم التربويّة المكتسبة | `‏/student/values-tree` |

**آليّة النشاط**: يفتح الطالب النشاط، يحلّه (نصّ / ترتيب صور / رفع ملفّ / اختيار)، ثمّ يسلّمه. بعض الأنشطة تُصحَّح تلقائياً وأخرى تنتظر مراجعة المعلّم. تُتاح إعادة المحاولة ضمن حدّ المحاولات، وتُحتسب **أفضل محاولة** لا تراكمها.

### النقاط والمستويات والشارات

- **النقاط (XP)**: تُكتسب من إتمام الأنشطة والتمارين والتحدّيات.
- **المستويات**: تصاعديّة عبر منحنى موحّد (كلّما زادت النقاط ارتفع المستوى بوتيرة متباطئة).
- **الشارات**: تُمنح آلياً عند تحقّق شرط (نقاط/مستوى/سلسلة/…)، وتُعرض المقفلة مع شريط تقدّم. المسار: `‏/student/badges`.
- **التيجان**: تكريم إضافيّ في `‏/student/crowns`.

### التحدّيات والسلاسل والفرق

- **التحدّيات (PvP)**: بهو التحدّيات `‏/student/pvp` — الانضمام لتحدٍّ مفتوح، أو **تحدٍّ موجّه** باختيار منافس محدّد ودعوته (قبول/رفض)، ثمّ اللعب والنتيجة.
- **السلاسل (Streaks)**: أيّام النشاط المتتالية تمنح مكافآت التزام.
- **الفرق**: عرض فريق الطالب وأنشطته في `‏/student/teams`.

### الاقتصاد (النقود والمتجر)

| العنصر | المسار |
|---|---|
| المتجر (شراء/استبدال) | `‏/student/shop` |
| مقتنياتي (تجهيز/استخدام) | `‏/student/my-items` |
| سجلّ النقود | `‏/student/coins/history` |
| الهدايا الواردة | `‏/student/gifts` |

### التفاعل

- **الرسائل**: مراسلة المعلّمين ضمن مدرسته.
- **تقييم المعلّمين**: `‏/student/rate-teachers`.
- **التحليلات الشخصيّة**: `‏/student/analytics`.

## 2. المعلّم

يبني المحتوى ويراجع الأداء ويدير الفرق ويصدر التقارير.

### إنشاء الأنشطة والتمارين

- **الأنشطة**: إنشاء/تعديل/معاينة/حذف (`‏/teacher/activities`). المحرّر غنيّ يدعم نصّاً منسّقاً ووسائط. النشاط الجديد يمرّ بمسار **اعتماد مرحليّ** (مدير المدرسة ثمّ الأدمن) قبل ظهوره للطالب، مع إمكان **إعادة تقديم** بعد الرفض.
- **بنك الأنشطة**: حفظ أنشطة قابلة لإعادة الاستعمال، ثمّ **نسخ قابل للتعديل** أو **إسناد مرجعيّ بلا نسخ**.
- **التمارين**: إنشاء/تعديل/حذف تمارين مع صفحة نتائج (`‏/teacher/exercises`).
- **إعدادات مكافأة الالتزام** للأنشطة: `‏/teacher/streak-settings`.

### المراجعة والتصحيح

| الإجراء | المسار |
|---|---|
| قائمة التسليمات للمراجعة | `‏/teacher/review` |
| مراجعة تسليم واحد وتصحيحه | `‏/teacher/review/{id}` |
| السماح بإعادة محاولة | `review/{id}/allow-retry` |
| **تمييز** تسليم متميّز / إلغاء التمييز | `review/{id}/feature` · `unfeature` |

التصحيح يدعم توجيه الدرجة لكلّ سؤال، مع مراجعة يدويّة عند الحاجة. التسليمات المميّزة تظهر لاحقاً في لوحة الأدمن.

### الفرق والتقارير

- **الفرق**: إنشاء/تعديل/حذف فرق، إسناد نشاط جماعيّ، وتصحيحه (`‏/teacher/teams`).
- **تقارير الطلاب والفصول**: `‏/teacher/students` و`‏/teacher/classrooms`، مع **تصدير PDF** لتقرير طالب أو فصل.
- **التحليلات**: `‏/teacher/analytics`. **الصدارة**: صدارة المعلّمين والطلاب.
- **التقييمات الواردة** من الطلاب: `‏/teacher/ratings`.
- **مقارنات الاستبيانات** القبليّة/البعديّة (مفلترة على طلاب فصوله): `‏/teacher/surveys/comparisons`.

## 3. وليّ الأمر

يتابع الأبناء، ويعتمد ما يتطلّب موافقته، ويشجّع، ويطّلع على أثر القيم.

### متابعة الأبناء

- **لوحة التحكّم**: `‏/parent/dashboard` — ملخّص أداء كلّ ابن.
- **تفاصيل الابن**: `‏/parent/child/{id}` — الأنشطة والنقاط والتقدّم.

### الموافقات

- **الأنشطة العائليّة المعلّقة**: `‏/parent/family-activities/pending` — اعتماد ما أنجزه الابن في البيت.
- **موافقة الوليّ المسبقة** (ميزة #23): نشاط يتطلّب إذن الوليّ قبل انتقاله للمعلّم — `family-activities/parent-approval/{id}/approve`.

### الاقتصاد والتشجيع

- **المدح**: `children/{id}/praise` — كلمة تشجيع تمنح نقاطاً محدودة.
- **الهديّة**: `children/{id}/gift` — إهداء نقود/عناصر للابن.

> ملاحظة اقتصاديّة: اقتصاد الابن (بعض المكاسب) قد يُؤجَّل حتّى موافقة الوليّ.

### الرسائل والاستبانات

- **الرسائل**: مراسلة معلّمي أبنائه فقط (معزولة).
- **مقارنات الاستبيانات**: `‏/parent/surveys/comparisons` — أثر القيم قبل/بعد على أبنائه.

## 4. مدير المدرسة

يدير كيانات مدرسته: الفصول والمعلّمين والطلاب وأولياء الأمور، ويعتمد الأنشطة والتقديمات، ويدير تعدّد المدارس.

### إدارة الكيانات

| الكيان | العمليّات | المسار |
|---|---|---|
| المعلّمون | عرض/إضافة/تعديل/حذف | `‏/school-admin/teachers` |
| الطلاب | عرض/إضافة/تعديل/حذف + تفاصيل | `‏/school-admin/students` |
| أولياء الأمور | عرض/إضافة/تعديل/حذف | `‏/school-admin/parents` |
| الفصول | عرض/إضافة/تعديل/حذف | `‏/school-admin/classrooms` |

> الحذف محميّ من الأثر الهدّام (cascade) — تُحسم التبعيّات بأمان.

### الاعتماد والتقديمات المعلّقة

- **اعتماد أنشطة المعلّمين** (المرحلة الأولى قبل الأدمن): `‏/school-admin/activity-approvals` (اعتماد/رفض) + صفحة تفاصيل موحّدة `‏/school-admin/activities/{id}`.
- **التقديمات المعلّقة**: `‏/school-admin/pending-submissions` — حسمٌ احتياطيّ مُقيَّد بالمدرسة عند عدم تجاوب المعلّم أو وليّ الأمر (اعتماد/رفض).
- **طلبات التسجيل** الواردة: `‏/school-admin/requests` (قبول/رفض).

### التسجيل والاستيراد والإعدادات

- **روابط التسجيل ورموز QR**: `‏/school-admin/registration-links` مع توليد رمز وتفعيل/تعطيل التسجيل.
- **استيراد/تصدير Excel**: `‏/school-admin/excel-management` (قالب، استيراد مستخدمين، تصدير بيانات) بسقف حجم آمن.
- **إعدادات المدرسة**: `‏/school-admin/settings`.
- **الإحصاءات والترتيب**: `‏/school-admin/statistics`.
- **تفاعل أولياء الأمور**: `‏/school-admin/parent-engagement`، و**مقارنات الاستبيانات** على مستوى المدرسة.

### تعدّد المدارس

يمكن أن يدير مدير واحد أكثر من مدرسة عبر **«المدرسة النشطة»** المحفوظة في الجلسة — كلّ الشاشات أعلاه تُفلتَر تلقائياً على المدرسة النشطة، ويبدّل المدير بينها دون خلط بيانات.

## 5. الدعم الفنّيّ

يدير تذاكر المستخدمين ويقدّم مساعدة محدودة على الحسابات.

### فتح التذاكر (لكلّ المستخدمين)

أيّ مستخدم مسجَّل — من أيّ دور — يفتح تذكرة من `‏/tickets`: إنشاء، عرض، ردّ، إغلاق. المسار عابر للمدارس والأدوار (يتطلّب تسجيل الدخول فقط).

### لوحة الدعم

محروسة بدور **الدعم الفنّيّ** (والسوبر أدمن يمرّ تلقائياً).

| المهمّة | المسار |
|---|---|
| لوحة الدعم | `‏/support/dashboard` |
| قائمة التذاكر / عرض تذكرة | `‏/support/tickets` |
| الردّ / الحلّ / إعادة الفتح / الإغلاق | `reply` · `resolve` · `reopen` · `close` |
| التصعيد / الإسناد | `escalate` · `assign` |

### إدارة المستخدمين (صلاحيّة محدودة)

`‏/support/users` — عرض/تعديل مستخدم، **إعادة تعيين كلمة المرور** (تفرض تغييرها عند الدخول التالي)، وتفعيل/تعطيل الحساب. **لا مساس بالحسابات المميّزة** (سوبر أدمن) — محميّة صراحةً.
