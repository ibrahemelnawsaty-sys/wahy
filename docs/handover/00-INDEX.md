## نقاط حرجة قبل الإطلاق (خلاصة)

1. 🔴 **كلمة مرور البريد:** كانت `MAIL_PASSWORD` مطابقة خطأً لكلمة قاعدة البيانات — ضع كلمة بريد `info@atheel-makkah.com` الصحيحة، وتحقّق بـ`php artisan mail:test`. (تفاصيل: دليل 05).
2. 🔴 **الـcron إلزاميّ:** بدونه لا تعمل النسخ الاحتياطية ولا المهامّ المجدولة. (تفاصيل: الرunbook §12).
3. 🔴 **النسخ الاحتياطي off-site:** الخادم بلا Auto Backup — فعّل Contabo Auto Backup أو وجهة S3. (تفاصيل: دليل 06).
4. ⚠️ **`APP_KEY`:** لا تُعِد توليده عند ترحيل بيانات قائمة. (تفاصيل: الرunbook §4).
5. ⚙️ **بعد النشر:** اضبط من لوحة الأدمن: العلامة، البريد/الجوال، رقم الواتساب، تفعيل فيديو الهيرو، وأعلام إظهار أقسام الصفحة الرئيسية.
